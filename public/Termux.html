4️⃣ Termux Main Commands

rm -rf        → Delete file
cd             → Open folder
cd ..          → Back to previous folder
ls -a          → Show hidden files
cp -r          → Copy folder
mpv            → Play MP3 Music
mkdir          → Create new folder
touch          → Create file 🗃️
pwd            → Show file path directory
zip -m         → Zip and delete old file
nuzip          → Unzip file
exit           → CTRL + D to exit Termux

5️⃣ Termux Shortcut Command Add

nano .bashrc
alias any_name='add file path and code'

alias 0='clear'
alias l='ls'
alias dl='/storage/emulated/0/Download'
alias yt='echo -e "\033[1;33m https://youtube.com/@hackedtips"'

source ~/.bashrc

6️⃣ Termux Extra Keys and Buttons
